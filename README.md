# PowerWise – Advances in CS

## Description
A web-based smart energy monitoring system that simulates electricity usage.

## Features
- User authentication
- Device and room management
- Energy simulation
- Dashboard analytics

## Technologies
- React
- Node.js / Express
- PostgreSQL
- Socket.IO

## How to run
1. Run backend: npm install && npm start
2. Run frontend: npm install && npm run dev
